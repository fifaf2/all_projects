ШПАРГАЛКА ПО VUE.JS
Проект PepkaStore, папка pepe-vue
Как что пишется. Примеры взяты из этого проекта.


1. ЧТО ЭТО

Vue — это фреймворк для интерфейса.
HTML остаётся HTML, а данные из JavaScript сами попадают на страницу.
Если данные меняются, страница обновляется сама. Это называется реактивность.

Сайт одностраничный (SPA): браузер не перезагружает весь сайт при переходе.
Меняется только кусок внутри <RouterView />.


2. КАК ЗАПУСТИТЬ

Открыть терминал в папке pepe-vue:

    npm install
    npm run dev

Сайт: http://localhost:5173
API должен быть запущен отдельно: http://localhost:5096


3. ПАПКИ

pepe-vue/

4. ФАЙЛ .vue — ТРИ ЧАСТИ

Один компонент = один файл .vue.

    <script setup>
      // логика: переменные, функции, запросы
    </script>

    <template>
      <!-- разметка. Здесь пишут директивы Vue -->
    </template>

    <style>
      /* стили. В этом проекте стили лежат в public/styles, не в компоненте */
    </style>

script setup значит: всё, что объявлено в скрипте, сразу видно в template.
Отдельно return писать не нужно.


5. main.js — СТАРТ

    import { createApp } from 'vue'
    import App from './App.vue'
    import router from './router'

    const app = createApp(App)
    app.use(router)
    app.mount('#app')

createApp(App)  — создать приложение из App.vue
app.use(router) — подключить переходы между страницами
app.mount('#app') — вставить приложение в div с id="app"


6. ref — ПЕРЕМЕННАЯ, КОТОРУЮ ВИДИТ СТРАНИЦА

    import { ref } from 'vue'

    const login_user = ref('')
    const products = ref([])
    const loading = ref(true)

В script пишут .value:
    login_user.value = 'pepe'
    products.value = response.data

В template .value НЕ пишут:
    <input v-model="login_user" />
    <p v-if="loading">Загрузка...</p>

Пустая строка: ref('')
Число:        ref(0)
Массив:       ref([])
Объект:       ref(null)


7. ВЫВОД ТЕКСТА {{ }}

    <h1>{{ product.title }}</h1>
    <p>{{ Number(product.cost).toFixed(2) }} ₽</p>

Внутри фигурных скобок обычный JavaScript.
На странице это уже готовый текст, не код.


8. v-model — ПОЛЕ И ПЕРЕМЕННАЯ СВЯЗАНЫ

    <input v-model="login_user" type="text" />
    <input v-model.number="cost" type="number" />
    <textarea v-model="description"></textarea>
    <select v-model="categoryId">
      <option v-for="cat in categories" :key="cat.id" :value="cat.id">
        {{ cat.name }}
      </option>
    </select>

Напечатал в поле — изменилась переменная.
Изменил переменную в коде — изменилось поле.

.number нужен для цены и количества, чтобы это было число, а не строка.


9. ДВОЕТОЧИЕ :  ЭТО v-bind

Связывает атрибут HTML с данными.

    <img :src="'/images/' + product.image" :alt="product.title" />
    <router-link :to="'/product/' + product.id">Купить</router-link>
    <option :value="cat.id">{{ cat.name }}</option>

Без двоеточия src="product.image" будет буквально текст product.image.
С двоеточием подставится значение.


10. СОБЫТИЯ @  ЭТО v-on

    <button @click="edit(product)">Изменить</button>
    <button type="submit">Войти</button>
    <form @submit.prevent="auth">

@click="имяФункции"     — по клику вызвать функцию
@submit.prevent="auth"  — отправить форму и НЕ перезагружать страницу

prevent обязателен на формах. Иначе браузер обновит страницу, как обычный HTML.


11. v-if / v-else / v-else-if — ПОКАЗАТЬ ИЛИ УБРАТЬ

Элемент вообще не попадает в страницу, если условие ложное.

    <p v-if="loading">Загрузка...</p>
    <p v-else-if="errorText">{{ errorText }}</p>
    <p v-else-if="products.length == 0">Товаров нет</p>
    <div v-else>...</div>

    <router-link v-if="!user" to="/signin">SIGN IN</router-link>
    <router-link v-else to="/profile">PROFILE</router-link>

    <button v-if="editingId" type="button" @click="clearForm">Отмена</button>

!user значит «пользователя нет».


12. v-for И :key — СПИСОК

    <ProductCard
      v-for="product in filtered"
      :key="product.id"
      :product="product"
    />

product — один элемент на этом круге
filtered — массив
:key="product.id" — уникальный номер. Писать всегда, иначе Vue путает элементы.

Так же:
    <div v-for="(item, index) in order.items" :key="index">


13. computed — ЗНАЧЕНИЕ, КОТОРОЕ СЧИТАЕТСЯ САМО

Магазин, поиск. Файл ShopView.vue:

    const filtered = computed(() => {
      const text = search.value.toLowerCase()
      return products.value.filter((product) => {
        const byCategory = Number(categoryId.value) == 0 || product.categoryId == Number(categoryId.value)
        const byName = product.title.toLowerCase().includes(text)
        return byCategory && byName
      })
    })

В template пишут filtered, без скобок и без .value.
Когда меняется search или categoryId, список пересчитывается сам.

Корзина, сумма. Файл CartView.vue:

    const total = computed(() => {
      let sum = 0
      for (let i = 0; i < items.value.length; i++) {
        sum = sum + items.value[i].cost * items.value[i].count
      }
      return sum
    })

В шаблоне: {{ Number(total).toFixed(2) }}


14. onMounted — КОД ПОСЛЕ ПОЯВЛЕНИЯ СТРАНИЦЫ

Запросы к API пишут здесь. До этого компонента на странице ещё нет.

    import { onMounted, ref } from 'vue'

    onMounted(() => {
      axios.get(API + '/Products/GetProducts').then((response) => {
        products.value = response.data
      })
    })

response.data — это JSON, который вернул C# API.


15. КОМПОНЕНТ

Маленький кусок интерфейса. Карточка товара: components/ProductCard.vue

Родитель передаёт данные через атрибут :product="product".
Ребёнок принимает их так:

    defineProps({
      product: {
        type: Object,
        required: true,
      },
    })

В template ребёнка переменная product уже есть.
Родитель подключает ребёнка:

    import ProductCard from '../components/ProductCard.vue'

Имя файла ProductCard.vue в шаблоне пишется так же: <ProductCard />.


16. РОУТЕР — СТРАНИЦЫ

Файл src/router/index.js

    { path: '/shop', component: ShopView }
    { path: '/product/:id', component: ProductView }
    { path: '/goods', component: GoodsView }

path — адрес в браузере
component — какой .vue показать
:id — кусок адреса. Для товара 5 адрес будет /product/5

В App.vue:

    <Header />
    <RouterView />

RouterView — место, куда подставляется текущая страница.
Шапка остаётся, меняется только страница.

Ссылка без перезагрузки:

    <router-link to="/shop">SHOP</router-link>
    <router-link :to="'/product/' + product.id">Купить</router-link>

Переход из кода:

    import { useRouter } from 'vue-router'
    const router = useRouter()
    router.push('/shop')
    router.push('/signin')

Текущий адрес:

    import { useRoute } from 'vue-router'
    const route = useRoute()
    route.path            // '/shop'
    route.params.id       // id из адреса /product/5


17. AXIOS — ЗАПРОСЫ К API

Адрес лежит в src/api.js:

    export const API = 'http://localhost:5096/api'

Подключение в компоненте:

    import axios from 'axios'
    import { API, showError } from '../api'

GET — получить:

    axios
      .get(API + '/Products/GetProducts')
      .then((response) => {
        products.value = response.data
      })
      .catch((error) => {
        showError(error)
      })

С параметрами в адресе:

    axios.get(API + '/Products/GetProduct', {
      params: { id: route.params.id }
    })

Это уйдёт как /api/Products/GetProduct?id=5

POST — создать:

    axios.post(API + '/Products/PostAddProduct', null, { params })

PUT — изменить уже существующее:

    axios.put(API + '/Products/PutUpdateProduct', null, { params })
    axios.put(API + '/Users/PutUpdateUser', null, { params })
    axios.put(API + '/Basket/PutUpdateBasket', null, { params })

DELETE — удалить:

    axios.delete(API + '/Products/DeleteProduct', {
      params: { id: product.id }
    })

Второй аргумент у post/put — тело запроса. У нас null, потому что данные идут в params, то есть в строку адреса.
Это как в методичке: /api/Users/PostAuthorizationUser?loginUser=...&passwordUser=...

.then — запрос удался
.catch — ошибка. showError показывает alert с message от API
.finally — выполняется всегда, например loading.value = false


18. КУКИ — КТО ВОШЁЛ

После входа весь объект пользователя кладётся в куку user.
Так же, как в PHP была кука saveLogin, только здесь хранится весь ответ API.

В SignInView.vue:

    cookies.cookies.set('user', response.data)
    location.href = '/profile'

Прочитать:

    const cookies = useCookies()
    const saved = cookies.cookies.get('user')
    if (saved && saved.id) {
      user.value = saved
    }

Выйти:

    cookies.cookies.remove('user')
    location.href = '/'

В main.js кука живёт 1 час:

    globalCookiesConfig({
      expireTimes: '1h',
    })

Роль админа: saved.role == 'Админ'
Страница товаров пускает только админа. Остальных отправляет в магазин или на вход.

20. КОРОТКИЙ СКЕЛЕТ СТРАНИЦЫ, КОТОРЫЙ НУЖНО УМЕТЬ НАПИСАТЬ

    <script setup>
    import { onMounted, ref } from 'vue'
    import axios from 'axios'
    import { API, showError } from '../api'

    const products = ref([])
    const loading = ref(true)

    function load() {
      axios
        .get(API + '/Products/GetProducts')
        .then((response) => {
          products.value = response.data
        })
        .catch((error) => {
          showError(error)
        })
        .finally(() => {
          loading.value = false
        })
    }

    onMounted(load)
    </script>

    <template>
      <p v-if="loading">Загрузка...</p>
      <div v-for="product in products" :key="product.id">
        <h3>{{ product.title }}</h3>
        <p>{{ product.cost }} ₽</p>
      </div>
    </template>
